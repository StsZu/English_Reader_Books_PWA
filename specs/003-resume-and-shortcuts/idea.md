# Аудіокнига: відступ після паузи і швидкі клавіші

**Стан:** погоджено й виконано 2026-10-22 (див. «Стан виконання» внизу). Стосується обох застосунків: English Reader і Polish Reader (`Polish_Reader_Books_PWA/specs/002-polish/tasks.md` → P15).

## Формулювання

Після «Пауза» → «Слухати» аудіокнига повторює ціле слово, а керувати програвачем і читалкою з клавіатури iPad неможливо.

| | |
|---|---|
| **Проблема** | 1) Відступ 1 с після паузи (етап A.1, `specs/002-audio-player/idea.md`) чути як повтор одного слова (~8 символів). 2) У читалці немає жодної швидкої клавіші. |
| **Для кого** | Читач на iPad із клавіатурою. |
| **Бажана зміна** | Після паузи нічого не пропадає і майже нічого не повторюється; пауза, перемотування й інші дії — з клавіатури. |
| **Користь** | Слухати й читати, не тягнучись до екрана. |

## 1. Відступ після «Пауза» → «Слухати»

Відгук: «краще 0». Чому не просто 0: до етапу A.1 відступу не було (програвач продовжував з власного місця), і коротке слово пропадало — звук, обірваний паузою, ще не дійшов до динаміка. Плавно приглушити звук перед паузою на iPad не можна: Safari не дає сторінці змінювати гучність `<audio>`.

Пропозиція:

- **Відступ 0,3 с** замість 1 с — приблизно стільки звук іде до динаміка на iPad: частина склада, а не слово.
- **Якщо на iPad знову щось пропадає або повторюється** — налаштування «Відступ після паузи»: 0 / 0,3 / 0,6 / 1 с (з Bluetooth-навушниками може знадобитися більше).
- **Довга пауза** (понад 5 хв або повторне відкриття книжки) — лишити 3 с, щоб легше згадати, де ви були. Питання: лишити 3 с чи теж 0,3 с?
- Повзунок, ±5 с і вибір доріжки — як і зараз, точно у вибране місце, без відступу.

## 2. Швидкі клавіші

Зараз у читалці немає швидких клавіш (є лише стрілки на самому повзунку, коли він у фокусі, і клавіші у вправах).

Загальні правила:

- Клавіші визначаються за фізичним положенням (`KeyboardEvent.code`), а не за літерою: однаково працюють з англійською, українською й польською розкладками.
- Не спрацьовують, коли фокус у полі введення, коли відкрито аркуш, діалог чи меню, і коли натиснуто ⌘ або Ctrl (⌘C та інші системні комбінації не зачіпаються).
- Пробіл не повинен спрацювати двічі, якщо кнопка «Пауза» лишилася у фокусі після дотику (пауза й одразу «Слухати») — обробник це блокує; перевіряється тестом.
- Список клавіш, який iPadOS показує при утриманні ⌘, працює лише для застосунків з App Store, тому довідка — власний аркуш (клавіша `?`).

### Обов'язкові (запит)

| Клавіша | Дія |
|---|---|
| Пробіл | «Слухати» / «Пауза». У режимі аудіокниги це аудіокнига, у режимі голосу — читання голосом |
| ← / → | Назад / вперед на 5 с |

Пробіл зараз гортає текст на екран униз; після зміни гортання лишається на ↑ / ↓ і PageUp / PageDown.

### Пропоновані

| Клавіша | Дія |
|---|---|
| Shift + ← / → | Назад / вперед на 30 с |
| [ / ] | Повільніше / швидше: 0,75 → 0,9 → 1,0 → 1,15 (на українській розкладці — «х» / «ї») |
| , / . | Попередня / наступна доріжка (на українській розкладці — «б» / «ю») |
| A | Перемкнути «Аудіокнига» ↔ «Голос» |
| Esc | Закрити аркуш, меню, панель (уже працює) |

### Для читання (за бажанням)

| Клавіша | Дія |
|---|---|
| Enter | Прослухати вибране речення голосом (як утримання) |
| T | Показати / сховати переклад речень |
| Shift + PageUp / PageDown | Попередній / наступний розділ |
| ? | Аркуш зі списком усіх клавіш |
