# R-W0: реальна перевірка `.polenuk` на iPad

Мета (R001, SC-01, D3): з'ясувати, як iPad поводиться з `.polenuk` і запасним `.zip` **до** того, як Reader навчиться їх імпортувати. Застосунок Reader цим тестом не змінюється й не розгортається.

## Підготовка на Mac

1. Тестові контейнери (вміст — синтетична польська «Lekcja druga» голосом macOS і Cat and Mouse з `build/013-sample`; поза git):
   ```zsh
   python3 -I make_test_containers.py <тека> <пакет.reader.json> <тека з MP3> [<пакет2> <тека2>]
   ```
   **Погоджене місце файлів Polenuk (користувач, 2026-11-11):** `/Users/szubar/Library/Mobile Documents/com~apple~CloudDocs/2_Books-0000/2Books/Polenuk-files`; на iPad — Файли → iCloud Drive → 2_Books-0000 → 2Books → Polenuk-files. dot скопіював туди 4 файли R001 без перезапису, SHA-256 збіглися; синхронізацію на iPad ще не підтверджено. Оригінали не змінювати; наявні файли не перезаписувати без перевірки й дозволу.
   Робочі копії асистента — у `build/r-w0-containers/` цього репозиторію (тека в `.gitignore`, у git не потрапляє): `lekcja-druga-pl.polenuk`, `lekcja-druga-pl.zip`, `cat-and-mouse-en.polenuk`, `cat-and-mouse-en.zip` (однаковий вміст для `.polenuk` і `.zip`; усі чотири проходять `validate-container` інструмента `f048707`).
2. Тестова сторінка `index.html` у цій теці — лише для поля вибору файла; без мережі, без збереження. Локально, без розгортання:
   Сторінку ще не опубліковано. **HTTP у локальній мережі не годиться:** `http://<Mac>.local:…` — не безпечний контекст, тому Safari не дає Web Locks (`navigator.locks` відсутній), і рядок «Web Locks» показав би «немає» хибно. Потрібна HTTPS-адреса. Підготовлено (не опубліковано): локальна гілка `r001-polenuk-page` від `main` (`1307f76`) лише з `public/r-w0/index.html`, `r-w0.css`, `r-w0.js` (без вбудованих скриптів і стилів — їх заборонила б CSP застосунку). Перевірено локально під тим самим CSP на `127.0.0.1`: безпечний контекст — так, Web Locks — є, читання частинами працює, помилок консолі немає. Публікація — лише з окремого дозволу (варіант — у `plan.md`, Р5). Без неї можна перевірити лише «Файли» (пункти 1–4 нижче).
   Встановлені English Reader і Polish Reader контейнер **ще не підтримують** (імпорт — R023); перевіряти вибір у них зараз не треба.

## Що перевірити на iPad і записати дослівно

**«Файли»**
1. Скопіювати `.polenuk` і `.zip` в iCloud Drive (окрема тестова тека) і на iPad («На iPad»).
2. Як показується `.polenuk`: піктограма, назва з розширенням, що відбувається при дотику (перегляд, «розпакувати», нічого).
3. iCloud Drive: файл, ще не завантажений на iPad (хмаринка) — що робить вибір у полі сторінки.
4. AirDrop з Mac на iPad: куди потрапляє `.polenuk` і `.zip`, чи пропонує iPad програму.

**Safari, тестова сторінка**
5. Рядок «Web Locks: є/немає».
6. Для кожного поля 1–5: чи можна вибрати `.polenuk` і `.zip` (чи вони сірі), що показує «Результат»: назва, розмір, тип, перші байти `50 4b 03 04`, «кінець каталогу знайдено: записів 4», ім'я першого запису `mimetype`.

**HTTPS-сторінка (опубліковано 2026-11-11, дозвіл «ok R001-preview» / «ok R001-wrangler-preview»):** `https://r001-polenuk-page-english-reader-books-pwa.sts-zubar.workers.dev/r-w0/` і `https://r001-polenuk-page-polish-reader-books-pwa.sts-zubar.workers.dev/r-w0/` — Worker Previews наявних воркерів, створені локально `npx wrangler preview --config wrangler.<мова>.jsonc --name r001-polenuk-page` з гілки `r001-polenuk-page` (`5c75492` = `main` + три файли `r-w0/`); унікальні адреси розгортань `0adc1a8b-…` (en) і `209c2063-…` (pl). Перевірено на Mac (WebKit, не iPad): HTTP 200 для трьох файлів, заголовок CSP застосунку, безпечний контекст — так, Web Locks — є, `.polenuk` читається частинами, помилок консолі немає. Production не змінився: `e938439c` (en), `141a3f7d` (pl), `main` = `1307f76`; на production `/r-w0/…` повертає лише запасну сторінку SPA. **Спостереження:** автоматична збірка Workers Builds для гілки не запустилась (watch paths: include `*`, exclude порожньо, за словами dot) — причина не з'ясована. Тимчасовий HTTP-сервер у мережі зупинено.

**Проміжний результат — Mac, Chrome (не iPad), 2026-11-11, за скріншотом користувача, переданим dot:** вибір файлів на HTTPS-сторінці: поле 1 — `lekcja-druga-pl.polenuk`; поле 2 — `cat-and-mouse-en.zip`; поле 3 — `lekcja-druga-pl.polenuk`; поле 4 — `cat-and-mouse-en.polenuk`. Показано результат лише поля 2: 3 468 227 байтів, `application/zip`, сигнатуру ZIP прочитано, 4 записи, перший `mimetype`. Результати читання полів 1, 3, 4 кадр не показує — не зараховано. Це не перевірка iPad: R001 і D3 не закрито; перевірка на iPad — окремо, результату ще немає.

**iPad, Safari, HTTPS-сторінка (2026-11-11), дослівно:** dot: «На iPad відкрийте те саме посилання в Safari й спробуйте вибрати файл .polenuk у першому полі.» Користувач: «теж все вибирається.» Зараховано лише: `.polenuk` вибирається на iPad у полі 1 (`accept=".polenuk"`). **Не підтверджено:** читання ZIP (кінець каталогу), рядки «Безпечний контекст» і «Web Locks», інші поля й файли, файл iCloud без завантаження, AirDrop, повний R001. Доповнення користувача там само, після «теж все вибирається.», дослівно: «zip теж відкривався». Зараховано лише: `.zip` на тестовій сторінці на iPad теж відкривається (номер поля, прочитаний каталог і Web Locks не названо — не зараховано). Найменша наступна перевірка — один скріншот сторінки на iPad після вибору `.polenuk` у полі 1, щоб було видно верх (безпечний контекст, Web Locks) і блок «Результат».

**Встановлена PWA** — не цим тестом: поле вибору всередині встановленої PWA English/Polish Reader перевіряється в R-W3 після реалізації імпорту (без production до окремого дозволу).

## Як вирішується D3

- `.polenuk` вибирається хоча б в одному полі (1–3) з iCloud Drive і локально, `slice` читає кінець каталогу → `.polenuk` лишається основним; у застосунку — той `accept`, що спрацював.
- `.polenuk` сірий у всіх полях, а `.zip` вибирається → основний `.zip`, `.polenuk` — лише назва для Mac/обміну, або перевірити поле 4 (без фільтра).
- Обидва недоступні → лишається тека `.reader.json` + MP3 (поле 5, як зараз).

Мова книжки не залежить від розширення: перевірка «польський `.polenuk` в English Reader → відмова» — у R-W2/R-W3, коли застосунок імпортуватиме контейнери.
